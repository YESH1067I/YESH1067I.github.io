# 💗 Чамд зориулсан нэгэн түүх

Хайртдаа зориулсан, утас болон компьютер дээр ажиллах төрсөн өдрийн романтик веб сайт. Сайт нь **интернетгүй байсан ч** үндсэн ажиллагаагаа гүйцэтгэнэ. Зөвхөн нэмэлт Google Fonts нь интернеттэй үед ачаална.

## ▶️ Яаж нээх вэ?

1. ZIP файлыг **Extract All** гэж задлаарай.
2. `our_little_universe` хавтсыг нээ.
3. **`index.html`** дээр хоёр дарахад Google Chrome, Edge зэрэг браузераар сайт нээгдэнэ.

Node.js, npm, build хийх шаардлагагүй.

## 📷 Зураг нэмэх

`assets` хавтас руу хамт авхуулсан зургуудаа оруулаад дараах нэрээр хадгална:

| Зургийн нэр | Хаана харагдах вэ? |
| --- | --- |
| `hero.jpg` | Сайтын эхний том зураг |
| `story-1.jpg` | Түүхийн 1-р бүлэг |
| `story-2.jpg` | Түүхийн 2-р бүлэг |
| `story-3.jpg` | Түүхийн 3-р бүлэг |
| `memory-1.jpg` | 1-р жижиг бэлгийг дарахад |
| `memory-2.jpg` | 2-р жижиг бэлгийг дарахад |
| `memory-3.jpg` | 3-р жижиг бэлгийг дарахад |
| `gift-1.jpg` | «Илиад»-ыг таасны дараа |
| `gift-2.jpg` | Цэцэгтэй дэвтрийг таасны дараа |

**Зураг оруулаагүй байхад** гоё өнгөтэй placeholder харагдана. Хэрэв зураг тань `.png`, `.webp` зэрэг өөр форматтай бол `content.js` доторх `photo`-ийн нэрийг тааруулж өөрчил.

Жишээ: `photo: "story-1.jpg"` → `photo: "бид-хоёр.png"` гэж сольж болно. Зургийг `assets/бид-хоёр.png` руу хийнэ.

## ✍️ Бичвэр солих

VS Code дээр **`content.js`** файлыг нээ. Дараах хэсгүүд бий:

- `hero` — Эхний том гарчиг, тайлбар, зураг.
- `story` — Гурван дурсамж, зураг болон тайлбар.
- `memories` — Дарж нээдэг гурван хайрцаг, жижиг мэндчилгээ, зураг.
- `bridgeQuote` — Дундах хайр дурлалын өгүүлбэр.
- `gifts` — Хоёр бодит бэлгийн сэжүүр, зөв хариу, зураг, мэндчилгээ.
- `final` — Эцсийн төрсөн өдрийн захидал.

`[Энд ... бичээрэй]` гэсэн өгүүлбэрүүдийг өөрийн үгээр солино. Бичвэрийг үргэлж **давхар хашилт дотор** байлга. Жишээ нь:

```js
text: "Бид анх танилцсан тэр өдрийг би одоо ч мартдаггүй. ♡",
```

⚠️ Сэжүүрүүдээ өөрчилж болно, харин `answers` дахь зөв хариунуудыг устгахгүй байвал таавар хэвийн ажиллана.

## 🎁 Хоёр бэлгийн оньсого

- **Нууц 1:** Одиссей болон Гомероор дамжуулж *«Илиад» ном*-ыг таалгана. «Илиад», «Илиада», `Iliad` гэх мэт хариуг зөвшөөрнө.
- **Нууц 2:** Цэцэг, мөрөөдөл, бичих хуудас гэсэн сэжүүрээр *цэцэгтэй дэвтэр*-ийг таалгана.
- Бэлэг дээр дарсны дараа хариултаа бичнэ. Хэрэв мэдэхгүй бол дараагийн сэжүүрийг хүсэж болно.
- Сүүлчийн сэжүүрийн дараа **«Нууцыг харах»** гэсэн сонголт гарна. Ингэснээр тааж чадаагүй байсан ч цааш явж чадна.
- Хоёуланг нь тайлсны дараа хамгийн сүүлчийн төрсөн өдрийн мэндчилгээ нээгдэнэ.

## 🌍 Онлайн байрлуулах

Хамгийн энгийн арга: `our_little_universe` хавтсаа Vercel / Netlify / GitHub Pages зэрэг статик сайт байршуулдаг үйлчилгээнд оруул. Vercel CLI ашигладаг бол энэ хавтас дотроо:

```bash
npx vercel --prod
```

Тэгвэл найз охиндоо илгээх холбоос гарна (Vercel-д нэвтэрч, төслийн тохиргоогоо баталгаажуулах шаардлагатай байж болно).

## 📂 Файлууд

- `index.html` — Хуудасны бүтцийн файл
- `styles.css` — Өнгө, дизайн, утасны дэлгэцийн зохицуулалт
- `content.js` — **Зураг, текст засах гол файл**
- `script.js` — Хайрцаг, захидал, оньсого болон зүрхний animation
- `assets/` — Өөрийн зургуудын хавтас

**Гол зүйл:** Бэлгийн хоёр нэр эхнээсээ ил харагдахгүй. Таасан/нууцыг тайлсан үед л гарна. ♡
